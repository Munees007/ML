# Experiment 13: Dashboard Analysis using Bricks AI

## Objective
Upload a dataset and build dashboards to generate insights and business reports.

## Procedure
1. Open Bricks AI and sign in.
2. Import the CSV or spreadsheet dataset.
3. Preview data and confirm column types.
4. Create dashboard tiles such as bar charts, line graphs, and KPIs.
5. Add filters and groupings for deeper analysis.
6. Save and share the dashboard with insights.

## Suggested reports
- Revenue trends over time
- Category-wise comparisons
- Top performing segments
- Missing value and distribution analysis

## Observations
Document patterns, anomalies, and recommendations that emerge from the dashboard.
