# Experiment 22: E-mail Classification using Levity

## Objective
Build a no-code email classification workflow using Levity AI.

## Procedure
1. Visit the Levity AI website and create an account.
2. Start a new project and choose the email classification template.
3. Upload a labeled dataset of emails and categories.
4. Train the model with a few examples per category.
5. Test the predictions on new email samples.

## Suggested categories
- Work
- Personal
- Spam
- Finance
- Customer Support

## Observations
- Review accuracy and classification confidence.
- Check misclassified email examples.
- Document useful workflow improvements.
