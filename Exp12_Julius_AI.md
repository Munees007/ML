# Experiment 12: Dataset Analysis using Julius AI

## Objective
Analyze a dataset with Julius AI to generate insights, charts, and summaries.

## Procedure
1. Open Julius AI in a browser and sign in.
2. Upload the CSV dataset from your local machine.
3. Select the target columns for analysis.
4. Ask Julius AI to explain trends, anomalies, and summary statistics.
5. Use generated charts and reports to describe patterns in the data.

## Suggested prompts
- "Summarize the dataset and key trends."
- "Show the correlation between columns."
- "Identify outliers and missing values."
- "Create a dashboard view with summary charts."

## Observations
- Check overall dataset size, missing values, and outliers.
- Compare trends across categories or time periods.
- Use the generated visual insights to support the final analysis.
