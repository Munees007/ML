# Experiment 23: Image Classification using Teachable Machine

## Objective
Build an image classification model with Google Teachable Machine.

## Procedure
1. Open Teachable Machine and select the Image Project option.
2. Create classes such as Cat, Dog, and Bird.
3. Upload sample images for each class.
4. Train the model and adjust the number of epochs if needed.
5. Test the model with new sample images and review predictions.

## Suggested workflow
- Add multiple images for each class to improve accuracy.
- Validate outputs using different lighting and backgrounds.
- Save the trained model for future use.
